# 孤独摇滚四人皮肤：后藤一里样板

本目录是后藤一里皮肤的实现样板。虹夏、凉、喜多沿用相同的组件层级和素材槽位，分别替换角色、文字与色彩；不要把波奇整套配色、发夹符号和背景位置原封不动复制过去。

## 视觉结构

1. **舞台底层**：粉白纸面、一个主色环境光、一张独立立绘。立绘只占留白区，不在每个卡片重复出现。
2. **内容层**：接近不透明的白卡、细边、轻阴影，标题与正文使用深色。消息、会话列表、设置页保持相同的阅读基准。
3. **功能层**：顶栏、导航、输入区使用轻玻璃。14px 模糊和低饱和度增强即可；不叠加大光晕、强反光和高强度颗粒。
4. **角色层**：品牌头像、助手头像、空状态与少量提示点缀。底部三个入口使用不同表情，保留会话、文件、更多文字和原有点击区，选中表情更清楚；其他操作保留功能图标。
5. **操作层级**：新会话/发送使用实色主色。诊断、工作区选择、更多等保持中性，不能全部做成主色按钮。

## 文件职责

| 文件 | 职责 |
|---|---|
| `public/theme-vars.css` 的角色主题块 | `--dsr-*` 语义色，以及 `--btr-*` 内容、玻璃、装饰色参数 |
| 本目录 `skin.css` 第 01 节 | 角色图片与标语槽位，所有图片路径相对本文件 |
| `skin.css` 第 02–06 节 | 标题、内容、功能、阅读与点缀规则 |
| `preview.html` | 不连接主机的组件预览；复用实际 styles/workflow/skin 样式，不额外画一套玻璃效果 |
| 实际手机/桌面页面 | 最终验收基准，不能只验预览页 |

### 乐队手账装饰

标题小票、蓝黄胶带、四角色配色条和低对比圆点底纹增强角色感，正文仍使用稳定白底。四角色色条是作品装饰，不是会话状态；会话标题旁的浅色短线也不承担状态含义。不要添加持续晃动或闪烁，导航标签、未读徽标和状态文字保持可见。侧栏吉他贴纸直接来自本地 `dist/skin-bocchi/assets/official/hitori/hitori_live.png`，未重新绘制。

| 山田凉 | 蓝色 | 蓝色短发、贝斯 | 稍冷的纸面；避免整页铺深蓝影响正文 |

只做三份独立主题登记与素材替换，不把它们全部挤进 bocchi 选择器。先完成一套实际页面验收，再推进下一套。

## 不可破坏的布局规则

- **不设置 `.topbar`、`.bottom-nav`、`.composer-wrap` 的 position/top/bottom/transform。**它们由共用布局控制，玻璃层不能把固定导航改成 relative。
- 不加会接管 fixed 定位的全页 transform/filter 祖先；背景立绘使用独立的无点击伪元素。
- 归档按钮保留 `--swipe-x` 与 `.revealed` 契约，不能在未展开时露出或拦截点击。
- 不给每条会话套新的外层 DOM；不改消息协议、缓存或事件处理。
- 移动端与桌面端的立绘构图分别验收。手机把脸留在标题右侧，桌面放在远端留白；不要仅缩放同一张桌面截图。
- 所有装饰 `pointer-events:none`，不覆盖滚动、选择、导航或发送操作。

## 验收清单

1. 320/390px 手机与桌面实际页面无横向溢出。
2. 长列表滚动后顶部栏、底部导航仍保持既有定位，输入区仍可见。
3. 归档关闭/半滑/展开三态，以及展开后按钮点击。
4. 中文、English、长代码块、长链接、审批、设置、空状态、皮肤选择卡。
5. 正文对比度至少 7:1，辅助文字与主按钮至少 4.5:1；图片背景不能代替计算中的稳定底色。
6. 减少动态效果、减少透明度和存储不可用场景。
7. 改根 public 后运行 `npm run sync-plugin`，确认插件副本一致，再跑检查。
