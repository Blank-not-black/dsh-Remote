# 结束乐队：四人皮肤系列

沿用后藤一里的「乐队手账＋表情导航」风格，四人分别作为独立主题出现在手机、桌面、管理页和插件页面；默认皮肤和已保存的选择不变。

|---|---|---|---|---|

## 文件结构

- `public/theme-vars.css`：三人各自完整的语义配色，包含正文、辅助文字、操作、状态、纸面与装饰参数。
- `public/skins/kessoku/skin.css`：虹夏、凉、喜多共享的纸面、卡片、手账装饰、导航、消息与归档样式。选择器只覆盖三套新主题，不影响波奇或其他皮肤。
- `public/skins/<角色>/skin.css`：角色资源、导航三张表情、标语、标题符号、立绘构图、选择卡配色。
- `public/skins/<角色>/preview.html`：复用实际样式的静态组件预览，不连接主机。
- `public/skins/<角色>/SOURCES.json`：所用原图及现有素材库的来源记录；没有重新绘制五官。
- 后藤一里的原样式保持在 `public/skins/bocchi/`，作为已验收的系列样板。

共享 CSS 必须先于角色 CSS 加载。图片变量使用 `url("../nijika/face.png")` 这类包含角色目录的路径，使其在共享文件与角色文件中消费时都能正确解析；只写 `url("face.png")` 会让共享样式到错误的目录取图。

## 视觉与交互约定

1. 单张 TV 版透明立绘、少量 Q 版贴纸、淡底纹和四色乐队胶带；正文保持深色，内容卡提供可靠白底。
2. 主按钮用足够深的角色主色，避免浅黄色配白字。正文对比度至少 7:1，辅助文字、白字按钮与导航文字至少 4.5:1。
3. 三项导航按 `data-view` 绑定不同表情，保留文字、未读徽标和点击区。角色的表情动作各不相同，不把波奇的慌张脸强加给其余三人。
4. 标题标记属于当前角色。四色胶带与列表短色条是作品装饰，不承担运行、审批或连接状态含义。
5. 不覆盖顶栏、导航、输入区的既有定位，不对全页添加 transform/filter。装饰不能拦截点击。
6. 滑动归档仍消费既有 `--swipe-x` 和 `.revealed`。卡片有 1px 边框，关闭状态的位移需要补偿这一边界；归档关闭时可见宽度必须为 0。
7. 立绘位置分别针对手机与桌面验收，至少检查 320/390px 手机画框。静态组件预览不能代替实际 WebUI 验证。
8. 修改根 `public/` 后运行 `npm run sync-plugin`，检查资源及插件副本，并完成主题与全量测试。

## 素材使用

三人均使用现有库中的 TV 无阴影立绘、同系列三款 Q 版头像及 Live 乐器贴纸。文件直接复制，未新增第三方依赖、CDN 脚本或在线图片请求；运行时所有图片都由网关本地静态托管。

来源字段沿用素材收集清单，不代表本轮完成了新的官网交叉核对。具体素材见各角色的 `SOURCES.json`。
