# 日常操作手册

[首页](README.md) · [AI 指引](ai-guide.md)

适用本库的源码基线；Android 和手机 Web 共用主要界面，桌面 Web 也有“会话、文件、更多”。HarmonyOS 是独立客户端，不能照搬所有入口。

| 想做什么 | 操作路径 | 完成后核对 | 影响与条件 |
| --- | --- | --- | --- |
| 添加手机连接 | DSH 插件面板“添加手机”，手机扫码或填写主机地址与配对信息 | 当前主机名称与连接状态，进入工作区/会话 | 配对信息敏感；手机不要填写 localhost |
| 检查连接 | 更多中的连接/服务器设置，或管理页连接诊断 | health、上游、mux/host 分开看 | 只读检查，参见 [连接](connection.md) |
| 选工作区 | 会话页选择工作区；新会话时核对名称和路径 | 新会话属于所选主机、工作区 | 新建会话有写入；不要用空参数猜 cwd |
| 正常发送 | 会话内输入后点击发送 | 等待 accepted 或查看原操作回执 | 可能调用模型；unknown 不能再次盲发 |
| 插队发送 | 启用长按插队设置，繁忙时按当前按钮提示操作 | DSH 是否接受插队，后续历史/队列 | 接受不代表当前工具立即被中断，见 [会话](sessions.md) |
| 查看审批 | 当前会话待办；更多 → 审批与操作回执 | 会话、工具、原因和最终结果 | 允许/拒绝是写操作；记录不包含所有自动放行调用 |
| 切换权限 | 当前会话的权限模式菜单 | 主机公布选项、当前模式、命令终态 | Auto review 是实验能力，有风险确认；仅影响该会话 |
| 创建分支 | 已完成回合的结果栏选择分支 | 跳到新分支会话，历史边界正确 | 创建会话；分支成功不会自动发送下一条消息 |
| 看子智能体 | 会话顶栏“子代理”，展开层级并选择节点 | 直接父会话、状态、只读记录 | 依赖 DSH 目录能力；第三方团队不等于内置子代理 |
| 管理插件 | 更多 → 主机插件 | 当前 profile、任务阶段、待重启状态 | 操作区分管理权限，见 [插件](plugins.md) |
| 文件传输 | 文件页选择主机/工作区及目录，再上传或下载 | 目标路径、大小及传输结果 | 需允许根和主机账户权限，见 [文件](files.md) |
| 开启通知 | 更多 → 通知与后台，按需开启轮询、审批/提问及峰谷提醒 | 系统通知许可、服务状态、主机规则 | 依赖 Android 权限与省电策略，见 [通知](notifications.md) |
| AI 排查 | 插件/控制台/连接诊断/手机首页的“AI 排查问题” | 目标目录、独立诊断会话与结论 | 打开面板不调用模型，开始诊断后使用主机模型额度 |
| 导出诊断 | 更多 → 关于与维护 → 本地操作日志 | 导出的脱敏 JSON；用户审阅后分享 | 无需反馈或主机在线；清除记录是单独操作 |

## 常见误解

- “已安装”“配置启用”“组件正在运行”不是同一个状态。插件配置启停通常需要重启 DSH。
- 费用、套餐、技能中心等页面依赖对应主机插件。缺失时显示不可用，不应显示为零或假装安装成功。
- 图片附件发给模型，与上传文件到主机目录，是不同操作。
- 归档不是永久删除。上游没有删除能力时，不能直接删会话文件作为替代。
- UI 上有按钮不代表当前主机支持完整动作；先看 capability、主机返回和最终回执。

实现与验证入口见 [源码依据](sources.md)。更完整的逐步界面说明在仓库 `docs/usage.md`、`docs/onboarding-guided-practice.md`。
