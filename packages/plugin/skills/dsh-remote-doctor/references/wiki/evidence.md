## 最小证据包

| 项目 | 建议记录 | 不应分享 |
| --- | --- | --- |
| 版本 | DSH、已安装插件、运行网关、App/WebUI 与 buildId | 不用源码版本替代运行版本 |
| 目标 | 系统、使用端、profile 名称、安装方式 | 完整个人路径、账号或公网地址 |
| 时间 | 问题发生时间和时区、最近升级/切网动作 | 整段历史轨迹 |
| 状态 | health 关键字段、双事件通道、HTTP 状态与固定错误码 | token、Cookie、认证头、二维码 |
| 操作 | 目标类型、失败阶段、回执/任务的脱敏关联信息 | 消息正文、工具输入、上传文件 |
| 对照 | 同手机不同网络、正常/坏会话、重启前后 | 未经授权创建任务或调用模型的结果 |
| 日志 | 相关日志末尾约 120 行内的必要片段，先脱敏 | 整个会话日志、配置文件、环境变量 |

“更多 → 关于与维护 → 本地操作日志”记录有限的操作阶段与匿名关联信息，可复制/导出。Android 使用系统文件选择器。它不包含所有后端错误；历史日志没保存的细节无法事后还原。即使应用已经过滤字段，分享前仍需用户审阅。

AI 可以整理这份草稿，但不自动上传日志或提交 Issue。用户确认公开内容后再自行提交；先排除已知限制、配置问题与上游错误，避免把所有失败都归为 Remote 缺陷。
