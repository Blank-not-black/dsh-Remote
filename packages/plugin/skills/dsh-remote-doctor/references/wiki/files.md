# 文件传输与目录范围

[首页](README.md) · [错误索引](errors.md)

文件页传输通过网关文件接口与主机账户权限工作。聊天图片发给模型是另一路能力，不能用文件上传成功证明模型读到了图片或文件。

## KB-FILE-01：403、路径不在允许范围、Windows 盘符不可见

**先看：** 当前主机/工作区、路径所属平台、显式允许根、文件真实路径、运行账户权限；区分 401 认证错误和 403 范围拒绝。

- `DSH_REMOTE_FS_ROOT` 多根在 Windows 使用 `;`，Linux/macOS 使用 `:`。不要按冒号拆开 Windows 盘符。
- Windows 默认范围包含当前用户目录与启动时可用的非 C 盘盘符；新挂载磁盘可能需要重启网关后重新发现，UNC 共享需显式授权。
- Windows 默认范围不会因工作区登记而开放 C 盘其他受限目录；junction/符号链接必须通过真实路径边界检查。
- Linux/macOS 的默认用户目录与经过 DSH 验证的工作区、显式根规则见当前网关实现。`DSH_REMOTE_FS_ROOT` 不是 DSH 所有工具的沙箱。
- 凭据目录/文件另有保护；范围允许不等于可以下载主机 token 或 Cookie。

**下一步：** 先检查目标是否合法、是否选错主机。确需新增授权时说明准确目录、影响和重启条件，由用户授权后修改；不要开放整盘或关闭真实路径检查作为默认修复。

**验收：** 在预期目录可列出/下载测试目标；越界与受保护文件仍被拒绝。不要读取用户无关文件做验证。

## KB-FILE-02：同名冲突、续传失败、409/422、上传中切主机

**先看：** 客户端提示、原上传任务、目标路径、大小、已有偏移与校验状态。409/422 的具体原因以接口错误与操作阶段为准，不能只看 HTTP 码猜测。

**判断：** 目标已存在、并发占用、偏移不符、SHA-256 不符、连接切换是不同分支。最大文件大小受 `DSH_REMOTE_FS_MAX_UPLOAD` 及账户/磁盘约束，当前默认 2 GiB。

**下一步：** 再次确认覆盖行为；按原任务恢复或在明确取消后重来，不把上传到 A 的迟到结果算作 B 的成功。只有用户授权后才创建测试文件或清理未完成上传。

**验收：** 正确主机与目标目录出现预期文件，大小/校验一致；中断不留下被误认为完整的文件；未经确认不覆盖已有文件。

源码：`gateway.js`（插件为 `gateway.cjs`）、`public/app.js`、`public/chat-files.js`。回归入口与专题见 [源码依据](sources.md)。
