# 蓝色大肥鱼：晴空海湾

保留原有鲸鱼娘立绘、表情与深海蓝主色，使用海浪留白、蓝白内容卡和表情导航，并补充爱心、星星、气泡与贴纸边框。角色图片沿用原文件，没有重新绘制五官。

## 视觉结构

- 晴空浅蓝纸面：根元素绘制柔和环境色，独立背景伪元素绘制海浪轮廓、淡表情底纹，以及 `sparkles.svg` 中的气泡、星星和爱心；装饰主要出现在留白处。
- 角色：品牌头像、标题左侧星星眼、标题右侧全身图、助手头像、侧栏与空状态。取消每条会话和每个分组反复叠加头像。
- 内容：会话列表和助手回复使用稳定白卡。诊断与工作区选择是中性入口，新会话使用实色深海蓝。
- 导航：会话、文件、更多分别使用默认脸、眨眼、星星眼；图片在原有图标位内，保留标签、未读徽标和点击区。
- 可爱点缀：立绘圆形贴纸框、选中导航的粉色小圆垫、新会话按钮的眨眼贴纸、第一张会话卡的小睡脸，以及桌面侧栏虚线贴纸框。它们不代表额外功能或状态。
- 动态：不持续上下摆动，不用动画争夺阅读注意力。

## 维护约定

`public/theme-vars.css` 仍负责语义配色；本目录的 `skin.css` 只匹配 `fish`，声明局部 `--fish-*` 表面与图片参数。不要修改其他角色的变量或选择器。

标题立绘挂在标题的伪元素上，标题预留右侧空间，不能再放回整个 `.workflow-start` 上压住连接条。手机 320/390px 和 English 标题需要分别检查。

导航、顶栏、输入区的定位由共用布局负责。不要覆盖它们的 position/top/bottom/transform，不对全页加 transform/filter。背景和装饰均不能拦截点击。

滑动归档消费既有 `--swipe-x` 与 `.revealed`；卡片有 1px 边框，收起位移包含 1px 补偿。检查关闭 0px、半滑、完整展开和确认框；不得只验静态预览。

`preview.html` 是不连接主机的静态组件样板，复用实际样式。改动后执行 `npm run sync-plugin`、主题专项与仓库检查，并以实际 WebUI 验收。
