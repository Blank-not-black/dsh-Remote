# 企鹅女管：终末地工业终端

两套主题共享同一角色与同一套组件：白昼 `penguin` 使用冷白、墨黑操作条与信号黄点缀；极夜 `penguin-night` 使用炭黑、石墨内容面板与信号黄交互。已有语义色保留，主要操作通过局部组件参数强化黑黄工业语言。

保留工程网格、主网格、硬边斜切、标尺、技术标签和黄黑警示纹。它们是终末地的视觉语言，不替换成乐队手账、粉色胶带或圆润玩具面板。

## 作品专属细节

- “终末地工业 / ENDFIELD”中文铭牌与官网三角阵列装饰。三角 SVG 从官网静态样式资源取得，保留原文件，不将它标成正式企业徽标。
- 帝江号、塔卫二与集成工业主题线路图。以官网的 [帝江与集成工业设定](https://endfield.gryphline.com/en-us) 和 [集成工业蓝图介绍](https://endfield.gryphline.com/en-us/news/1340) 为参照，绘制轨道、节点和生产输送线；不是游戏地图或实时数据。
- 桌面在阅读区右侧留白显示线路图，消息卡仍有稳定底色；手机仅保留靠右淡出的线路边缘。
- 主要按钮右侧改用三角阵列识别块，保留壁纸中的警示纹，让品牌识别比通用施工条纹更突出。
- 本地文件及来源见 `SOURCES.json`。运行时只读取皮肤目录内文件，不请求官网资源。

## 组件层级

- 标题：切角黑底“终末地工业”标牌、三角阵列、信号黄短线和淡工程编号 03；全身企鹅挂在标题的独立留白，不能压进连接入口。编号是固定美术元素，不是任务计数。
- 内容：列表、诊断、工作区和消息采用直角面板、切角标记、黄色边角与消息侧边线。白昼为稳定白底，极夜为石墨底。正文和辅助文字保持清楚，阅读区留白保留网格与大斜切块。
- 主操作：白昼用墨黑与白字，极夜用信号黄与深色文字。两套主按钮右侧均使用官网三角阵列装饰，不承担运行状态。
- 导航：默认脸、眼镜脸、眯眼笑对应会话、文件、更多；保留标签、徽标和点击区。导航采用炭黑直角条、信号黄顶边与标签。
- 角色：品牌、助手、标题、桌面侧栏与空状态承担主要形象展示，不给每条内容反复盖章。

## 文件与约束

基础语义色与工业壁纸色继续位于 `public/theme-vars.css`。本目录 `skin.css` 声明局部内容面板变量并实现两套组件；只匹配两个企鹅主题。角色原图均保留，没有重新绘制五官；新增两张 SVG 的来源与绘制说明单独记录。

不要修改顶栏、底部导航、输入区的既有定位，不对全页添加 transform/filter。装饰不能截获点击或遮住未读徽标。

归档沿用既有 touch 处理、`--swipe-x` 与 `.revealed`。卡片的 1px 边框需要位移补偿，关闭状态不得露出按钮。至少验证关闭、半滑、展开、点击确认框。

`preview.html` 可切换白昼与极夜，使用独立手机画框复用实际样式，不保存实际主题偏好、不连接主机。最终验收仍要覆盖实际 320/390px 手机和桌面界面。

更新后运行 `npm run sync-plugin`，检查源文件与插件副本，并完成主题和全量检查。
