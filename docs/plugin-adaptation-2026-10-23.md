2026-10-23，基于 `0.8.0-rc.9` 的未发布源码。保留工作区此前的实验性插件折叠、Android 版本码、英文根 README、知识库和自更新修复；本轮没有发布或部署。

## 适配状态诊断

已适配插件的卡片显示具体状态：未安装、配置未启用、运行状态未知、等待启动或依赖、启动失败、待重启、接口待读取验证、读取成功、接口不兼容、接口缺失、读取失败或超时、主机拒绝读取。附有知识库链接。

列表只检查安装/运行元数据和可选服务方法是否存在，不调用费用查询、任务快照，不读取技能正文，不激活冷会话。用户主动打开页面后，实际读取结果才作为接口证据；证据按主机、令牌、插件版本保存至多五分钟。旧连接、旧工作区、旧页面的响应不能更新当前状态。接口读取失败仍可从对应页面重试；主机已确认缺少必需方法时不提供可用入口。

待重启诊断只针对本次发生变更的对应插件，不因其他插件的修改把所有适配都标为待重启。插件配置与运行快照仍是两个状态，不把已安装等同于已生效。

## 自定义余额与网关额度

`insights.mjs` 在既有只读费用摘要上新增：

- `customBalances`：由主机配置索引匹配的可见渠道，保留名称、币种/积分单位、余额、状态和供应商查询时间；兼容旧版单项余额。负余额可显示，缺失余额保持未知，不合计不同币种。
- `gatewayQuotas`：仅主机已启用且未隐藏的来源，显示来源状态、查询时间、掩码账户、供应商和已用百分比窗口。部分账户失败时仍显示其他成功账户。

最多 40 个余额条目、20 个网关来源，每个来源最多 16 个账户、每账户 8 个窗口。配置、URL、请求头、凭据、认证索引、密钥配置状态和原始错误消息均不透传。查询失败不把缓存金额或额度伪装为当前有效数据。

数据来自费用插件现有快照，不额外请求供应商、强制刷新或修改插件配置。既有官方余额/套餐开关、USD API 账本与 Plan 非实付等值区分继续保留。

## 团队状态

明确展示计划审查，包括上游 `awaiting_review`、`awaiting_feedback`；分别呈现交付检查、阻断项和可展开警告。交付警告不是执行失败，执行结束也不是交付通过。只有插件同时报告 `deliverable=true` 与 `delivery.ok=true` 才显示可交付。

继续只读、按工作区内队长会话归属筛选；不调用团队停止、调度或任务修改接口。

## 任务看板

适配包为 `@linxin666/dsh-client-ui-task-board`，本轮发布包基线 `0.4.8`、数据 schema 6。入口位于该插件的已安装卡片，需要配置启用且运行状态 active；未安装时不增加默认功能入口。

```text
GET /remote/api/task-board?workspaceId=<已注册工作区 ID>
```

主机 Remote 插件只调用已加载的 `taskBoard.snapshot()`，按已注册工作区筛选，不开放上游通用 HTTP/RPC 代理。保持 Remote 令牌/设备密钥鉴权及 `no-store`，拒绝 POST、重复/额外参数、任意路径和未知工作区。没有服务或不兼容时返回明确不可用状态，不退回读取用户账本文件。

第一阶段包含：任务标题/说明/状态，最近三次执行的有界摘要、失败原因和可用会话，验收状态，cron 或单次计划的启用状态、主机时区及下次执行时间。支持状态、文本和归档筛选。隐藏任务和未绑定工作区的任务不进入列表，列表中说明该范围；不推断未绑定任务属于当前工作区。

最多返回 200 个任务，未归档任务优先，运行中任务及最近更新优先；截断时提示。会话跳转只暴露主机工作区登记的执行会话，外部报告没有运行会话。看板列、执行结果、验收结果分别显示；`done` 不等于验收通过，异常/无效验收不伪装为质量通过。

页面只在打开、可见时每 15 秒读取。工作区切换会清除旧结果并取消旧请求；关闭取消读取。同一数据不重建卡片，有变化时保留展开和已有会话按钮焦点。返回插件列表保留原筛选和滚动位置。

暂不接入新建、运行、暂停、修改定时计划、删除任务或自然语言解析；未更改任务看板自身的数据或配置。
