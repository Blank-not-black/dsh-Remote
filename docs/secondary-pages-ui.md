# 二级页面视觉统一（2026-10-17）

本轮以现有「更多」一级页面为基准，统一其下的设置页面及插件子页面。版本保持 `0.8.0-rc.2`，保留工作区里此前的反馈修复、独立子代理页和新版 DSH 适配。连接地址列表在 rc.3 之后按 [主机与连接布局优化](hosts-layout.md) 收紧了行高与窄屏排版。

## 页面与交互

| 入口 | 二级页面组织 |
| --- | --- |
| 主机与连接 | 连接地址、访问令牌、云中转、主机管理、高级目录组织 |
| 外观与输入 | 对话与输入、外观与语言、预设提示词 |
| 模型与提供方（手机端已有入口） | 提供方配置、原有加载/空状态和配置操作 |
| 通知与后台（手机端已有入口） | 消息与提醒、可展开的后台与排障 |
| 关于与维护 | 版本与贡献者、公告、反馈与支持、本地数据 |
| 主机插件 | 返回更多；进入技能/费用后返回原插件列表，保留列表及滚动位置 |

设置页采用相同的「返回更多 → 图标、标题与说明 → 分组卡片」结构。24px 页面标题、20px 卡片圆角、12px 控件圆角和主题语义色沿用一级页面。说明文字完整换行；按钮、选择器及开关点击区域至少 44px。窄屏允许按钮换行，桌面内容宽度与更多页一致。未增加桌面端原本没有的模型/通知功能入口。

现有设置控件以 DOM 节点移动的方式归组，没有重建表单、删除控件 ID 或替换业务监听器。网络模式在桌面 DOMContentLoaded 后延迟创建，改为挂载到已预留的输入分组，并显露原先为空的分组。语言切换复用原控件，不重复添加网络设置。插件、技能、费用和回执页面统一字号、卡片、按钮与空状态样式；折叠/确认、公告自动弹出和读取逻辑保持原控制器负责。

使用 `cognitive-psychology-ux` 的一致性、分组和触摸目标原则，以及 `design-everyday-things` 的返回映射与反馈检查。启发式自查 **8/10**：入口、分组、返回关系及不兼容/空状态有界面和回归证据；“用户理解所有状态反馈”仍需要真实用户及 Android 实机验证。这不是用户研究评分。

## 本轮文件

- `public/workflow.js`：设置二级页面结构、分组、一级入口说明和中英文文案。
- `public/workflow.css`：二级设置、插件、技能、费用及回执页面的共享视觉规则。
- `public/network.js`：延迟创建的网络设置挂入输入卡片。
- `public/extensions.js`：插件管理返回更多，嵌套功能返回保留的插件列表。
- `public/app.js`、`public/desktop/desktop.js`：为插件页面提供返回更多的回调。
- `tests/extensions-ui.test.js`、`tests/network-policy.test.js`：返回层级、失效连接隔离、延迟挂载、语言切换不重复控件及原 change 事件。
- 本文及通过 `npm run sync-plugin` 更新的对应插件副本。
