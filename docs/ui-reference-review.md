# 0.8 界面调整草稿

参考对象为用户指定的 [Clarklevis1995/dsh-mobile](https://github.com/Clarklevis1995/dsh-mobile)，核对版本为 `87325cfecf364e55248b2f35ef9cb4c80790f41a`。查看了实际工作区、浅色聊天和设置截图，以及 `Design/design-spec.md`、`DeepSeekHarnessMobile/Core/Theme.swift`。仓库说明这些截图来自 iOS；不将其称为 Android 实机证据。

## 本轮取舍

- 首页采用“工作区选择 → 主操作新会话 → 最近会话”的顺序，待办保留显式处理区域；工作区路径继续可查看。
- 新会话使用整行主按钮，会话列表减少逐项边框和嵌套卡片，顶部去掉英文装饰标题。
- 底部三个入口改为圆角浮动导航；面板及导航保留实色兜底，只在支持时增强轻微背景模糊。五套现有主题和用户选择继续有效。
- 聊天输入框占满一行，模型、指令、附件和发送收在下方工具栏；运行中仍保留显式插队。正文不再层层包进卡片，代码及宽内容继续在各自容器滚动。
- 更多页按“连接与工作”“偏好与维护”分组，统一图标、圆角、间距和触控范围，清除只有隐藏项的空分组。
- 页面、列表更新取消装饰性的位移/淡入，减少刷新时的抖动。状态、错误和操作反馈仍保留。

实现为 Remote 自有 DOM/CSS 和现有主题变量；没有复制参考项目的品牌插画、图标资源或新增依赖。参考项目中的轨迹页面、iOS 系统材质和手势未作为本轮新功能加入。

## 源码与交付边界

源文件为 `public/workflow.js`、`public/workflow.css` 和 `public/motion.js`；插件 public 副本由 `npm run sync-plugin` 生成。校验记录在 `dist/ui-reference-check.log`，浏览器实拍在 `dist/ui-reference-preview/`。

`npm run check` 最终结果为 513 项，505 通过、8 跳过、0 失败。浏览器检查涵盖深浅主题、更多页分组、模型面板和运行中的排队/插队按钮；375/390 像素窄屏未出现页面横向溢出。通过界面提交的模拟消息在测试主机中只记录一次。桌面更多页另检查了 1280 像素宽度。

本次设计检查当时遵照用户要求：不构建新版本、不部署、不提交、不发布。随后 2026-10-16 的 rc.2 候选构建已纳入这些 UI 调整，当前交付与验证边界见 [rc.2 试测说明](rc-0.8.0.md)。本页浏览器检查使用隔离模拟主机，不访问真实 DSH profile 或模型；软键盘、安全区和真实手机手势仍需真机确认。
