# 公告摘要与折叠分区

0.8.1 起支持公告摘要与折叠分区，0.8.0 客户端仍显示兼容正文。本记录说明公告格式与显示方式。

公告可以保留完整正文，同时提供一段默认可见的摘要和若干可展开分区。适合版本发布、活动说明等较长公告：先显示节日祝福、关键更新与交流群信息，再按需展开详细介绍。

## 格式

```json
{
  "id": "release-example",
  "title": "版本发布公告",
  "content": "完整纯文本正文，包含摘要和所有详细内容，供旧客户端显示。",
  "summary": "默认可见的祝福、更新摘要和重要信息。",
  "sections": [
    { "title": "详细更新", "content": "完整更新内容。", "expanded": false },
    { "title": "后续计划", "content": "计划与尚未上线的说明。", "expanded": false }
  ],
  "actionUrl": "https://github.com/Blank-not-black/dsh-Remote/releases",
  "actionText": "查看版本与下载"
}
```

`content` 仍然必填，不能只保留摘要。旧客户端忽略新字段后，仍显示完整正文；新客户端显示摘要和分区，不再重复显示 `content`。

`summary` 最多 2000 字符；`sections` 为 1～8 项，每项标题最多 160 字符、正文最多 10000 字符，摘要及所有分区标题／正文合计最多 20000 字符。`expanded` 只有布尔值 `true` 才会默认展开，其他情况默认折叠。

结构不完整、包含空分区或超出限制时，整体回退为完整正文，避免悄悄丢掉部分内容。标题、摘要和分区正文均为纯文本；HTML 与 Markdown 标记不会被作为代码执行或解析成组件。

## 显示与交互

- 公告弹窗与历史公告共用同一渲染逻辑；历史缓存会保留摘要及分区。
- 主页公告卡片优先显示摘要。
- 分区使用浏览器原生 `details`／`summary`，支持点击和键盘展开、再次收起；标题触控区域至少 44px。
- 展开分区不会确认已读或提交投票，下载链接、投票与“知道了”仍沿用原流程。
- 配色使用现有主题变量，兼容浅色、深色和蓝色大肥鱼主题。

仅更新在线公告数据，无法让已发布的 0.8.0 App 获得折叠功能；需要包含新代码的客户端或 WebUI。本轮未更新线上公告、安装客户端或发布新版本。

## 本轮验证

`tests/announcement-content.test.js` 覆盖完整正文回退、默认折叠与显式展开、文本转义、格式／长度限制、弹窗及历史缓存一致性。连同既有公告与投票检查共 16/16 通过。

全量工作区检查为 1002 项：983 通过、19 跳过、0 失败；此数量包含工作区其他正在进行的改动，不能全部算作本功能新增测试。

隔离浏览器使用真实弹窗结构、样式与生产渲染函数：390×844 下 5 个分区默认关闭、约 197 字摘要可见，标题区域均为 44px，无横向溢出；实际点击展开、Enter 收起均通过，没有触发已读操作。浅色、深色及大肥鱼主题布局检查通过。证据与预览在 `dist/announcement-collapse-2026-10-24/`。
