# 团队、任务看板 UI 与文本排版验收

日期：2026-10-23。版本维持 `0.8.0-rc.9`，Android versionCode 维持 `8009`。本次为未提交的本地改动，不部署、不发布。

## 改动

- 团队：概览数字、计划审查、交付状态与阻断分区；成员按卡片展示，角色、模型、当前任务及会话入口分开，去掉重复的“未运行”标签。
- 任务：桌面卡片网格、手机单列；区分看板状态、执行结果和独立验收，合并相同失败原因；计划、摘要、父任务及会话入口有独立层级。数量随搜索、状态及归档筛选变化。
- 刷新保留详情展开状态；相同团队快照不重建 DOM。服务暂不可用后恢复时，即使数据没变化也重新显示列表。
- 排版：元数据不再沿用正文的保留空白规则。用户撰写的描述、消息、执行摘要和技能正文仍保留原始换行。移除 `workflow.css` 中覆盖新团队组件的旧规则。
- 设置：窄容器中的选择器排到说明下方，避免说明被挤成窄列；桌面说明按单词自然换行。费用页的来源和查询时间随宽度折行，额度数字保持完整。
- 大肥鱼皮肤：白色不透明卡片、浅蓝阅读区、柔和边框和角色标题点缀；图案不透过卡片正文。所有新增装饰都限定在 `html[data-theme="fish"]`，不修改会话滑动操作区。
