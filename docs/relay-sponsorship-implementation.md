# 赞助中转实施与验收

[赞助中转服务规则](relay-sponsorship-terms.md)规定对外权益和办理方式。本页用于下一版本的本地实作、运营准备和上线验收。现行试运营的操作仍见[现行试运营说明](relay-sponsorship-pilot.md)。

## 订单接口的本地验证

首阶段可在隔离 broker 的 `sponsor` 选项中传入 `serviceOrders: true`。生产启动命令仍使用试运营流程。新订单接口的请求体使用 `packs` 数组，每个元素对应一个服务月的购包数。首次开通只接受一期，续费按可预付的期数接受选择，`POST /sponsor/api/applications/{id}/add-packs` 接受当期加购。后台审核提交实际到账时刻 `paidAt` 和实际到账金额 `verifiedAmountCents`（以分计），与订单报价核对。草稿中的开通或逾期续费日期为预估，审核通过后返回正式期别。

## 激活文件导入

审核通过后，申请人可在浏览器办理页下载中转激活文件。运营者也可在审核后台的「申请通过通知」下载文件，作为附件发给对应用户。文件从签发起最长有效 7 天，最晚到中转资格到期。重新生成时前一份作废。文件只用于绑定中转资格，主机保留自己的私钥，下载内容不包含长期中转密钥、Remote 令牌或申请查询凭证。绑定后的同一主机在有效期内可以用原文件重试。

在主机 Remote 管理页或 Android「设置 → 云中转」导入。手机需要先通过可信局域网连接主机。只有设备权限时，在主机本机管理页确认导入。主机绑定后会通知已连接的新版 Android App 根据当前传输模式配置，并在公网会话查询成功后保存公网地址。首次配对、证书变更或普通 HTTPS 需要手机确认，导入不会改动原局域网连接。

导入失败时可按提示刷新并重试，或在办理页领取中转密钥，在管理页粘贴配置。主机已绑定但手机配置失败时，可重试当前手机，或按原方法手动配对和添加公网地址。线上下载和激活需要对应的云端更新。

隔离订单验证覆盖支付前库存预留与失效、人工审核、跨月重新占库存、同资格预付和到期后的绑定保留。该模式下 `/sponsor/` 提供首次开通、续费和加购订单，`/sponsor/admin` 可检查截图并人工填写到账金额和时间。办理页只显示订单用量。加购资格及逐包计量、邮件退款和留存、兜底额度及客户端切换仍需按下列验收项接入后启用。测试数据目录一旦初始化新订单模式，重新打开时仍使用相同模式。

## 服务期、资格与库存

- 保存每期开始和结束时刻、原始月度日期、对应资格和订单。首次开通从批准时起算。提前续费从原结束时刻接续。宽限期内续费从批准时重新起算，恢复原域名、公钥和主机绑定。到期即停止数据转发，72 小时只用于保留资源。
- 有效、待审核与宽限期的同一资格去重计数，总名额为 100。付款页开启收款前短时锁定可售名额及各期流量包库存，锁定单独从可售余量扣减。付款单及时提交后转待审核。到期前或宽限期内提交的有效续费单跨截止审核时，继续保留原绑定。不能履约且已经收款的订单进入人工退款流程。
- 每期基础费用 ¥5，购买包 ¥5／个。新资格首次购买一期。续费最多覆盖含当前期在内的连续三期。每期可随开通或续费订单选包，或在生效后 72 小时内补买。每资格、每服务期最多新买两包。
- 全站库存键为目标服务期开始时刻所在的北京时间年月，每月 20 包。预购跨月时逐期预留。若首次开通或到期后续费因审核跨月导致实际开始月份改变，在生效前校验新月份库存。库存冲突由人工确认调整或退款。未生效包退款时释放原归属月份的库存。
- 对订单金额、资格状态、库存、服务期和到账记录做一致性校验。重复提交、重复审核或进程重启不能重复发放额度、重复占位或扣减库存。基础额度按服务期发放，提前审核下一期时保留当前期的已用量和权限。

## 包留存与兜底额度

以现有计量单位为准，1 GB 为 1,000,000,000 字节。常规额度对上下行合计计量。每期按基础 5 GB、上期留存的单包、新购买的包依次扣减，购买的多个包分开记账。只允许留存当期购买且全期实际用量为零的一包。归档时保留各包用量，保证跨期审核有据可查。

留存以邮件发送时间为准，常规申请在该期结束前发送。边界例外由运营人员人工判断。允许审核跨期，并将批准的包追加到紧接的下一服务期，保留下一期已有用量。已留存的包不可再次留存。留存包提供文件权限，不消耗下期个人购买数量或全站销售库存。

当文件传输耗尽常规额度时，关闭该资格的文件流，单独启用 1 GB 兜底额度。兜底只允许普通 HTTPS 下的文本对话、图片预览和实现这两项所需的连接操作。转发前按现有请求策略识别允许的操作。文件浏览、上传和下载不能占用兜底额度。兜底额度以同一周期独立记账，不重置常规已用量，不结转，不在购买页列为购买权益。触发时显示「文件传输额度已用完，仍可发送文本和预览图片」。兜底用尽后关闭该资格的数据转发。

## 人工审核和退款

- 开通、续费、购包和退款由运营人员核对付款记录后执行。审核记录包含必要的订单、目标月份、金额和操作结果。付款截图、邮件和退款凭证与中转日志分开处理。
- 未开始的预付月份可从末期往前整期退款。任意未来期的包可单独退款。以退款邮件送达时间判断目标期是否已开始，后端将及时收到的退款申请涉及的未来权益暂停生效，审核通过后撤销对应权益并释放包库存。拒绝申请后恢复原权益，发生服务中断的由运营人员核实处理。
- 已生效月份的退款仅处理无法开通或正常使用的例外。按批准的退款范围撤销权益并保留已用量。单退最后一个包时立即取消文件权限，剩余普通 HTTPS 文本和图片权限仍按当期可用额度执行。

## 按申请编号联系用户

运营者在 `/sponsor/admin` 按用户 App 显示的「App 联系编号」搜索，打开「发送站内消息」。Android App 开通或用原查询凭证恢复申请后，用该编号作为收件箱。续费和加购保留原联系编号，各笔订单仍可单独留言。换机后用原查询凭证恢复同一个收件箱。

审核通过后，运营者可在「申请通过通知」点「投递站内激活」。首次开通投递到对应申请，续费投递到原 App 收件箱及本次续费申请。有效期最长 7 天，最晚到资格到期。有效期内重复投递复用原消息。邮件附件和站内激活各自有效，最终都只能绑定该资格对应的一台主机。

用户在 Android「设置 → 云中转 → 站内消息」点「领取并配置主机」，再核对局域网主机地址并点「应用到此主机」。只有设备权限时仍需主机端确认。流程失败可刷新后重试，也可使用原密钥和激活文件手动配置。站内消息正文不包含激活凭证，领取需要已恢复的私密查询凭证。

App 返回前台时检查一次，之后有已保存登记的设备在前台每分钟检查。发现新增未读时显示通用提醒，可在「设置 → 云中转 → 站内消息」打开收件箱。消息离线保留，打开目标会话后才标记已读。申请凭证和消息正文只在隔离的中转 WebView 中读取，App 主页面只接收登记状态和未读数。Android 客户端与云端办理页需一同更新以支持直达收件箱。

## 传输迁移和隐私

- 下一正式版先提供按主机切换的入口。设置页允许提前切换，旧加密连接因政策到期被拒后仍可从连接失败页进入。说明普通 HTTPS 的可见范围，经用户确认后用原域名和主机连接重连。客户端连接失败时不能自行降级。
- 为现有加密资格保存首期原定截止时刻。续费、预付和购买包均不延长旧加密资格。切换入口可用后再执行服务端截断。截止后拒绝新的端到端加密连接并关闭已建立的加密流，保留仍有效资格的普通 HTTPS 数据通道。验证已经无法连接旧主机入口的用户也可完成切换。
- 核对生产环境的 Nginx、broker 和运维采集。日志、缓存、临时文件、调试转储和备份不能留存对话、图片、文件内容或访问凭证。日志仅记录运营需要的统计和状态。示例 Nginx 配置会记录 `$uri`，应确认生产只记录预定义路由类别或关闭相应访问日志。公开隐私承诺随生产配置验收后生效。

## 开发顺序与验收

1. 先实现服务期、订单和库存状态及隔离测试，校验同一资格的续费与预付。覆盖月末和闰年、72 小时边界、并发预留、跨月审核、审核重试及旧资格读取。
2. 实现月度动态额度、逐包计量、留存和 1 GB 兜底。覆盖 5／10／15／20 GB、跨期晚审核、已用一字节的包、重复留存、断开文件流、兜底文件拒绝和重启后用量延续。
3. 重做开通和续费页，接入人工审核操作。付款前和提交后分别核对期别、费用、锁定时限和订单状态。测试整期退款只能从尾部开始、未来单包退款、退款跨期和库存归还。
4. 完成普通 HTTPS 默认、状态提示和旧加密切换。使用旧配对与新版客户端验收，确认拒绝加密后不会静默降级，确认后能用原连接继续。校验未续费到期、已续费恢复和保留绑定。
5. 用隔离实例验证 100 个名额和并发文件流下的实时对话。核对公网出站量与中转双向账本，分别确认用量边界和生产隐私配置。运行 `npm run check`。改 `public/` 或网关后运行 `npm run sync-plugin`，提交前遵守仓库对同步产物的限制。

测试使用临时目录和测试密钥。模拟付款、审批和邮件，避免触碰生产状态和真实 `~/.dsh-remote`。部署、正式发布和生产数据迁移需要维护者另行授权。
