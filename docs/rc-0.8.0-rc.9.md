# 0.8.0-rc.9 变化与验证范围

2026-10-22 源码快照。Remote 版本为 `0.8.0-rc.9`，本轮 DSH 适配目标包含 `0.2.1-rc.2`；两者是不同产品的版本。rc.9 是正式版前的候选版，本地构建、安装和公开分发分别核对，不凭源码版本推断 npm 标签或线上附件。

## 用户可见变化

| 变化 | 当前行为 |
| --- | --- |
| 三入口导航 | 会话、文件、更多；主机插件、审批与回执、连接和偏好集中在更多页。 |
| 手机端逐步引导 | 八步覆盖连接、会话、消息、结果、文件、分支、AI 排查和反馈；只打开已有入口，不代发或代操作。 |
| 引导收纳 | 完成或整体跳过后隐藏首页入口；“更多 → 偏好与维护 → 新手引导”列表末尾可重新学习。暂停仍保留首页续学入口。 |
| 默认鱼皮肤 | 未保存有效主题时使用蓝色大肥鱼，保留已有选择。引导入口使用普通设置行与小头像，不放在更多页顶部。 |
| 分支与会话恢复 | 完成回合提供分支入口；新建或打开分支后切换到目标会话，保持主机与会话归属。是否支持仍取决于上游能力。 |
| AI 排查与反馈 | 从手机首页打开说明，再由用户开始；修复诊断跳转与异步状态处理，小屏反馈表单保持可滚动。使用主机模型与额度。 |
| 发送结果诊断 | 区分明确拒绝与未知结果，未知时先核对历史与回执，不自动重复发送；保留白名单失败阶段信息。 |
| 文件上传 | 修复同名覆盖、续传和主机切换竞态；图片附件与传到主机目录仍是不同功能。 |
| 新会话错误提示 | 避免启动时写打开冷会话，并按会话归属展示错误；当前会话的真实权限恢复错误仍保留。 |
| Auto review 与仿真修复 | 主机权限目录、审批记录接入更多页；修复普通结果误记拒绝、乱序与缓存清理；命令依据操作终态确认，失败或失联不自动重复。JSON 分片、multipart 和路径错误响应同时修复。 |

详见[使用指南](usage.md)、[逐步引导](onboarding-guided-practice.md)、[发送结果与会话错误修复](receipt-and-session-error-fixes.md)、[DSH rc.2 适配与上传验证](dsh-0.2.1-rc2-upload-validation.md)。其他主机旧反馈中未记录的上游根因不能事后补回，也不能据这些修复宣称所有偶发错误已消失。

## 平台与构建

- Windows：此前已完成本地 Desktop profile 的 rc.9 插件安装、配置保留、重启与网关/DSH/双事件通道验证。安装记录属于具体构建，后续源码调整不自动覆盖该安装。
- Android：沿用 Capacitor 壳与同一套手机 WebUI。rc.9 已有本地 APK 构建和资源校验；本轮页面截图来自隔离浏览器，不能替代相机、通知、后台和网络切换的实机验收。
- Linux：补充临时目录隔离的极端场景、重启与连接测试；Linux 专属用例在 Windows 上可能跳过。平台用例、CI 和实体笔记本的结果分别记录，不以 Windows 测试代替 Linux 通过。
- macOS：主发布 CI 配置包含 Apple Silicon 的 `dsh-remote-macos-arm64`，复用全量检查、ad-hoc 签名和隔离启动冒烟。未做 Apple 公证，Intel 使用插件或源码。此处不声称本地已运行 macOS 产物或云端构建已经成功。
- HarmonyOS：仍为独立 `0.6.26` 工程，本轮未移植手机逐步引导或构建 HAP。

独立网关内置 Node，供需要单独管理网关的用户使用；常规 npm 插件已经带网关源码，无需再下载二进制。构建与发布命令、平台范围和副作用见[发布指南](release.md)。
