## 云服务器中转（0.8.0-rc.2）

使用自己的云服务器时，见[自建云服务器中转引导](self-hosted-relay.md)。当前设置页没有自定义服务地址输入框；需通过独立 CLI 接入，或先在实际网关启动环境中配置自建控制地址，再使用内置客户端。以下是公共试用的开通方式。

在「更多 → 主机与连接 → 云服务器中转」填入运营者私密发放的个人中转密钥，点击「绑定并开启」。主机 Remote 插件管理页也有入口。首次开通会绑定此主机，本机生成的私钥不会上传，客户端随网关启动，无需另外运行中转脚本。已有本次 `owner-preview` 试用可点击「接管已有试用连接」，沿用原地址和密钥。

复制专属 HTTPS 地址，在手机添加该地址并填写**自己 Remote 的访问令牌**。中转密钥只用于主机接入，不代替 Remote 鉴权。设备密钥可查看状态，开通/停用需要仅本次操作使用的主机管理令牌。

每日上传与下载合计 **5GB**，北京时间零点重置，由云端持久记账。设置页显示连接、有效期、已用和剩余额度；用满会关闭该用户公网传输，零点恢复，其他用户不受影响。本地地址仍可管理。停止中转会断开经该入口连接的设备，DSH 和 Remote 网关仍需保持运行。此功能面向受邀开发者试用，尚无支付功能，详见 [中转说明](../relay/README.md)。

## 服务器与网络模式

在「更多 → 主机与连接」管理地址、令牌、备注和分组。会话首页的连接条可打开状态和恢复操作。每个地址与令牌组成独立连接身份；同地址不同令牌不应覆盖。二维码可导入多个备用地址。

手动选择服务器会被尊重；自动选优按组设置并测速。切换地址或令牌后清除旧主机的会话、队列、审批、模型、文件路径与请求归属；读取中的旧响应不得覆盖新状态。

网络模式可选自动、弱网和正常。弱网减少历史分页并延长只读等待；操作请求失败时先核对是否已经生效，尤其是发送消息。不能把超时视为“必定没发送”。「弱网时关闭流式输出」默认开启：弱网下只显示已完成的消息与工具结果，隐藏流式思考和尚未返回的调用；标准网络不受影响，可在「更多 → 外观与输入 → 对话与输入」关闭。

## 会话与历史

主列表展示顶层会话，子代理在主会话中查看。DSH 标记 `blank` 的空会话会隐藏，产生首轮内容后恢复显示。离开新建空会话时，客户端只在确认没有有效内容、运行、队列或草稿等情况下尝试归档；上游归档可恢复，不是删除磁盘日志。

进入会话先展示当前连接身份的本地历史，再与 DSH 历史对齐。缓存/同步/离线标记用于判断数据新鲜度，缓存不能代替上游状态。Web 渲染窗口为 180 条，内存最多 5000 条；更早内容分页读取。IndexedDB 每个身份最多保留 10 个会话，每会话最多 250 条、约 750000 字符的事件数据，并有受限 localStorage 回退。手机重置会清理历史缓存。

「回到最新」只在确实离开底部时出现：滚轮或拖动滚动条回到底部会立即恢复跟随，点击卡片、展开工具或选中文字不会在底部留下“有新内容”标记；上翻期间到达的消息与流式内容计入未读，点击按钮后恢复跟随并补齐最新内容。

每个回合的工具调用与思考合并为一行「工具与思考 · N 项」，默认收起，展开后仍是逐条工具行和思考段；运行中的回合显示「运行中」并有轻微光晕，分组不会吞掉审批、提问和消息正文。

0.8 Web/Android 繁忙时普通发送固定排队，旁边显示「插队发送」；手机可额外开启长按快捷插队。模型和思考档位从输入框旁独立打开，指令菜单保留指令与权限。导出、压缩可在会话更多菜单直接执行，无需先插入文本再发送。插队提交 `session.prompt` 的 `mode:'steer'`，不自动降级。DSH 接受请求不代表当前工具已经中断；鸿蒙手势保持其原有实现。

支持操作回执的新网关会在提交消息、创建会话等动作前登记固定操作编号，断线只查询原操作。结果未知时在「更多 → 操作确认」查询，并核对主机会话；不能把未知理解为失败。确认结束跟踪后，再次提交会产生新操作，可能重复已经执行的动作。旧网关保持原 RPC 路径，没有相同的回执保证。

已明确工作区时可直接新建会话；文件页也可将当前已有目录登记成工作区。原工作台绑定与批量发现子目录移到主机连接中的高级选项，普通刷新不自动创建工作区。

模型与思考档位来自 DSH 的模型元数据；自定义提供方的协议和真实字段由 DSH 适配器决定。API 密钥通过 DSH 凭据接口写入，不保存到 WebUI 服务器列表或历史缓存。

会话中的待回答卡片显示简短摘要，点击卡片或「去回答」打开完整问题。长题干在弹窗内独立滚动，底部保留「提交」；桌面已处理的问题会从手机同步移除。

## 文件与图片

文件页使用网关允许根，支持目录、预览、下载、分块上传、续传、暂停与取消。默认上限 2 GiB；分块上传完整提交前做 SHA-256 校验。冲突、忙碌或校验失败须按提示处理，不能直接覆盖并假定成功。

聊天文件卡片和文件链接可下载到手机。`报告.docx`、`团队/报告.md`、`./报告.pdf` 按所属会话的工作目录解析，缺少工作目录时会提示；仍受网关允许根限制。新 Android 壳显示系统下载完成或失败原因，文件保存到 `下载/dsh-remote/`；旧壳和浏览器只确认已交给系统或浏览器下载。附件主机接口不兼容时会提示更新主机插件，有明确文件路径时可回退文件接口。

Windows 可跨默认授权盘符浏览，UNC 需显式授权；Linux/macOS 可访问用户目录及校验过的 DSH 工作区。具体范围见[配置](configuration.md)。这是 Remote 文件接口边界，不是主机终端或模型工具的全系统沙箱。

图片以 `session.prompt` 图片块发送；是否真正理解图片由 DSH 和模型能力决定。可选视觉桥接的主机要求见[网关模块](modules/02-gateway.md)。对话里的图片以缩略图显示，点击（桌面端也可回车）打开全屏预览：双击放大/还原，点空白、× 或按 Escape/Android 返回关闭；桌面端此前只显示占位符，现已同步渲染。回复里的 Markdown 图片（`![说明](路径)`）同样可预览：相对路径按当前会话工作区解析，经网关文件接口读取，失败时显示「图片无法加载」而不是下载。

## 插件与会话洞察

[插件中心](plugin-center.md)操作当前主机确认的 profile。不能确认管理能力时只读，配置启停需重启 DSH 生效；关闭页面不取消主机任务。Remote 自身与核心插件受保护。

[上下文与费用](plugin-insights.md)在会话顶部更多操作中打开，分别依赖 `dsh-context` 和 `dsh-cost-meter`。缺失显示不可用，不能生成假零。Remote 自身 `/stats` 费用是已知价格表的估算，未知模型的零估算不能理解为免费；洞察费用来自插件账本，两者不合并，供应商账单是结算依据。

## 通知、公告与更新

Android 可启用审批/提问通知、任务完成通知和后台轮询。后台轮询间隔可选 30 秒、1 分钟、5 分钟、15 分钟；Doze 与厂商省电策略可能延迟。峰谷提醒在「更多 → 通知与后台」开启手机通知；时间窗口、节假日、提前量与峰/谷提醒类型读取 DSH 的 `dsh-cost-meter` 配置。Android 后台接收器每 5 分钟更新规则，使用有效期内的通知时间表，不要求保持 DSH 页面打开；不会继续使用旧版写死的 9/12/14/18 点计划。需配套当前主机 Remote 插件，允许系统通知并将省电设为无限制。系统仍可能延迟通知或限制 dataSync 前台服务运行时间；回到应用会恢复已开启的接收器。浏览器和鸿蒙有各自的后台限制。详见[峰谷通知与 issue #18 处理](peak-reminders-and-issue18.md)。

审批与提问提醒需开启「审批/提问通知」并允许系统通知；后台接收还需启用后台轮询。新 Android 壳使用独立的「审批与提问提醒」通知渠道，同一请求前后台及重连重放只提醒一次，收到已处理事件后清理通知。点击通知进入所属服务器和会话；服务器已移除或令牌已变更时提示重新连接。

公告来自中央 HTTPS 源，短期缓存，源不可达时保留成功结果或回退内置文件。WebUI 前台每 30 秒检查，回到前台/网络恢复也会补查。未读新公告自动弹出，点击「知道了」后不再重复弹出；版本落后提醒显示期间暂缓弹出公告。新界面可在「更多 → 关于」查看公告及往期公告。支持单选、填空、多选与混合问卷，成功提交后才保存提交标记；翻页保留内存草稿。旧单选在网关不可用、网络失败或 401 等情况下可直连既有收集器托底；含填写内容的新表单只提交当前网关，普通反馈没有相同回退。格式、限制与本地验证边界见[公告表单与团队适配](announcement-forms-and-teams.md)。

「更多 → 审批与操作回执」上半部显示当前主机的待审批和待回答，可直接允许、拒绝或打开提问；下半部查询网络中断后的操作回执。回执为空不代表没有待审批。子代理在父会话卡片展开后点击名称进入，返回时回到父会话。Android 系统返回键依次关闭弹窗、返回设置上一级、回到会话首页，首页再次返回才退出。

试测云中转文件传输每路上传和下载分别限速 100 KiB/s，200 MB 约需 33～34 分钟；实际时间还受网络、协议和重连影响。小图、会话同步和实时事件不使用同一文件限速链路。大文件可通过可达的局域网或 VPN 直连主机地址传输。

Android 更新展示进度、速度、校验和失败状态。新壳支持下载时校验后交给系统安装器；旧壳走兼容路径，浏览器复用已下载 Blob。检查更新时先核对实际包版本与清单，不以版本 JSON 单独证明 APK 更新成功。

WebUI 共六套主题：默认深空、落日、易北爱乐厅、草原孤塔、黑曜白、蓝色大肥鱼；未显式选择时跟随系统。HarmonyOS 当前有自身四套色板，不能据 Web 主题数量宣称六套。

反馈中的兼容性诊断和崩溃记录摘要由用户明确勾选，默认关闭。崩溃预览最多 3 条，摘要经现有反馈字段提交，完整本地日志不自动上传。

「更多 → 关于与维护 → 本地操作日志」可独立查看、刷新、复制、导出和清除用户端的操作诊断记录，无需提交反馈或连接主机。记录最近 160 条、最长 24 小时的操作阶段、耗时、错误位置、连接恢复与后台状态，不保存对话正文、请求参数、凭证或完整文件路径。Android 导出使用系统文件选择器，断网也能保存 JSON 后自行提供给开发者。相同 RC 版本的不同构建通过日志中的 buildId 区分，详情见[本地操作日志](local-operation-logs.md)。

## 子代理查看

从对话顶栏的「子代理」进入独立全屏页面，进入时才读取。箭头展开下一层，点击卡片选中节点，在详情区查看所在分支、直接父会话和状态，再选择「打开只读记录」。手机选中后会滚到详情，可用「返回层级」回到所选节点。搜索和状态筛选只检查已读取节点，保留匹配节点的祖先关系；「收起分支」和「刷新」控制目录展开与更新。「返回对话」关闭页面并保留草稿和阅读位置。这里只展示 DSH 内置子代理，不包含第三方插件自定义的追问分支或团队任务，详见 [子代理查看说明](subagent-viewing.md)。

## 回合结果栏

手机/App 与桌面 Web 的回合结束后，可在回复下方复制最终结果、从该回合创建分支、展开查看输入/输出与缓存用量，并查看结束时间。历史未加载完整时用量会标注「已知用量」；主机未提供用量时显示 `—`。分支成功后打开新会话，不会自动发送消息。详见 [回合结果栏](turn-results.md)。
