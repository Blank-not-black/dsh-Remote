# 客户端使用与平台差异

[文档首页](README.md) · [配置参考](configuration.md)

## 页面与能力

| 项目 | Android / 手机 WebUI | 桌面 WebUI | HarmonyOS 源码 |
| --- | --- | --- | --- |
| 导航 | 会话、文件、主页、插件、设置 | 侧栏与工作区，按需打开抽屉 | 手机 Tabs，宽屏 Navigation 分栏 |
| 会话、审批、提问、目标、子代理 | 支持 | 支持 | 支持主要流程，细节以模块文档为准 |
| 图片附件 | Android 相机/相册，浏览器按可用能力回退 | 文件选择 | 系统图片选择器 |
| 插件中心 | 独立插件页 | 独立插件页 | 已有移植，最近修复仍需真机回归 |
| 上下文与费用洞察 | 支持，需主机对应插件 | 支持，需主机对应插件 | 尚未移植 |
| 自定义模型提供方编辑 | 手机设置页支持 | 消费模型目录与思考档位，不复制完整编辑器 | 不保证编辑器功能对齐 |
| `dsh-ui` / HTML 代码块预览 | 安全只读子集 | 相同子集 | `dsh-ui` 降级源码，无 Web 渲染器移植 |
| 本地历史缓存与窗口化渲染 | 共用 `history.js` | 共用 `history.js` | 不使用该 Web 实现 |
| 通知与后台 | Android 系统桥/前台服务；浏览器受平台限制 | 浏览器通知能力 | 系统通知/长时任务，侧载权限有限制 |
| 功能测试页 | 保留导航，ASR 已移除 | 无 Android ASR 桥 | 保留系统 ASR 诊断 |

源码支持不等于最新安装包已包含，也不代替真机验收。主项目基线 `0.7.4`，HarmonyOS manifest 仍为 `0.6.26`；当前 Release CI 构建 Android 与 Windows/Linux 网关，不构建 HAP。

## 服务器与网络模式

在「设置 → 服务器」管理地址、令牌、备注和分组。每个地址与令牌组成独立连接身份；同地址不同令牌不应覆盖。二维码可导入多个备用地址。

手动选择服务器会被尊重；自动选优按组设置并测速。切换地址或令牌后清除旧主机的会话、队列、审批、模型、文件路径与请求归属；读取中的旧响应不得覆盖新状态。

网络模式可选自动、弱网和正常。弱网减少历史分页并延长只读等待；操作请求失败时先核对是否已经生效，尤其是发送消息。不能把超时视为“必定没发送”。

## 会话与历史

主列表展示顶层会话，子代理在主会话中查看。DSH 标记 `blank` 的空会话会隐藏，产生首轮内容后恢复显示。离开新建空会话时，客户端只在确认没有有效内容、运行、队列或草稿等情况下尝试归档；上游归档可恢复，不是删除磁盘日志。

进入会话先展示当前连接身份的本地历史，再与 DSH 历史对齐。缓存/同步/离线标记用于判断数据新鲜度，缓存不能代替上游状态。Web 渲染窗口为 180 条，内存最多 5000 条；更早内容分页读取。IndexedDB 每个身份最多保留 10 个会话，每会话最多 250 条、约 750000 字符的事件数据，并有受限 localStorage 回退。手机重置会清理历史缓存。

繁忙时可排队发送。「长按插队」默认关闭；启用后手机短按与长按使用配置的默认/另一方式。插队直接提交 `session.prompt` 的 `mode:'steer'`，不自动重试或降级。DSH 接受请求不代表当前工具已经中断。桌面布局与鸿蒙手势细节不能直接套用手机说明。

模型与思考档位来自 DSH 的模型元数据；自定义提供方的协议和真实字段由 DSH 适配器决定。API 密钥通过 DSH 凭据接口写入，不保存到 WebUI 服务器列表或历史缓存。

## 文件与图片

文件页使用网关允许根，支持目录、预览、下载、分块上传、续传、暂停与取消。默认上限 2 GiB；分块上传完整提交前做 SHA-256 校验。冲突、忙碌或校验失败须按提示处理，不能直接覆盖并假定成功。

Windows 可跨默认授权盘符浏览，UNC 需显式授权；Linux/macOS 可访问用户目录及校验过的 DSH 工作区。具体范围见[配置](configuration.md)。这是 Remote 文件接口边界，不是主机终端或模型工具的全系统沙箱。

图片以 `session.prompt` 图片块发送；是否真正理解图片由 DSH 和模型能力决定。可选视觉桥接的主机要求见[网关模块](modules/02-gateway.md)。

## 插件与会话洞察

[插件中心](plugin-center.md)操作当前主机确认的 profile。不能确认管理能力时只读，配置启停需重启 DSH 生效；关闭页面不取消主机任务。Remote 自身与核心插件受保护。

[上下文与费用](plugin-insights.md)在会话顶部更多操作中打开，分别依赖 `dsh-context` 和 `dsh-cost-meter`。缺失显示不可用，不能生成假零。Remote 自身 `/stats` 费用是已知价格表的估算，未知模型的零估算不能理解为免费；洞察费用来自插件账本，两者不合并，供应商账单是结算依据。

## 通知、公告与更新

Android 可启用审批/提问通知、任务完成通知、后台轮询和峰谷提醒。后台轮询间隔可选 30 秒、1 分钟、5 分钟、15 分钟；Doze 与厂商省电策略可能延迟。峰谷提醒按北京时间处理，工作日 9/12/14/18 点，周末 9 点。浏览器和鸿蒙有各自的后台限制。

公告来自中央 HTTPS 源，短期缓存，源不可达时保留成功结果或回退内置文件。WebUI 前台每 30 秒检查，回到前台/网络恢复也会补查。历史公告在通知设置中查看。单选投票成功后才保存已投记录；手机 WebUI 在网关不可用、网络失败或 401 等情况下可直连既有收集器托底，普通反馈没有相同回退。

Android 更新展示进度、速度、校验和失败状态。新壳支持下载时校验后交给系统安装器；旧壳走兼容路径，浏览器复用已下载 Blob。检查更新时先核对实际包版本与清单，不以版本 JSON 单独证明 APK 更新成功。

WebUI 共五套主题：默认深空、落日、易北爱乐厅、草原孤塔、黑曜白；未显式选择时跟随系统。HarmonyOS 当前有自身四套色板，不能据 Web 主题数量宣称五套。

反馈中的兼容性诊断和崩溃记录摘要由用户明确勾选，默认关闭。崩溃预览最多 3 条，摘要经现有反馈字段提交，完整本地日志不自动上传。
