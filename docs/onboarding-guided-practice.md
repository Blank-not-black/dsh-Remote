# 手机端逐步新手引导

适用范围：手机网页和使用同一套 WebUI 的 Android App。电脑端继续使用已有的下载安装、扫码配对向导；本次补上连接后的学习路径，未给桌面 WebUI 或 HarmonyOS 增加同样的教学组件。

## 实际路径

首次打开手机首页，最上方显示“第一次用？一步一步带你上手”。用户点击后开始，每次只显示一项任务，操作说明可展开。每一步的按钮直接打开已有界面或定位实际控件。引导可以收起、跳过单步、暂停，也可以整体跳过。完成或整体跳过后，首页不再显示入口，仅在“更多 → 偏好与维护”列表末尾保留“新手引导”，刷新后仍保持收起；暂停后刷新则显示继续入口，不擅自切换页面或打开练习表单。

| 步骤 | 直接到达的操作 | 完成与异常处理 |
| --- | --- | --- |
| 1 连接电脑 | 主机与连接设置 | 解释电脑、DSH、网关、手机的关系，区分安装码和连接码。未确认当前连接时不能点下一步，仍可明确跳过。 |
| 2 工作区与会话 | 选择或新建会话面板 | 解释电脑目录和会话的区别，核对路径与主机提供的类型。只有会话打开、历史成功加载后才确认完成。 |
| 3 第一条消息 | 实际输入框，或用户主动放入示例草稿 | 说明模型和额度、模型按钮、指令、排队与插队。只在当前连接及会话收到普通消息的 accepted 回执后完成；不把点击、未知结果、拒绝或斜杠命令当成功。 |
| 4 回复、审批与回执 | 现有审批与操作回执面板 | 解释接受与回复的区别，停止、审批与提问，以及结果未知时先查询、核对，避免重复发送。 |
| 5 图片与文件 | 实际文件页与上传入口 | 解释对话图片和电脑文件传输的区别、路径、进度和上传后的核对，不自动选文件。 |
| 6 分支 | 会话中的真实分支按钮 | 解释从回复位置开新会话、保留原会话，但不撤销文件改动。按钮不可用时说明条件并允许继续，不强迫新建分支。 |
| 7 AI 排查 | 现有 AI 排查说明面板 | 说明只读诊断、独立会话、自己的模型和费用；由用户自己决定是否开始。面板打开时教学卡隐藏，关闭后恢复进度。 |
| 8 有效反馈 | App 内反馈表单 | 教“页面 → 操作 → 预期 → 实际”、复现频率、设备环境，解释日志可选和凭证保密。保留已有草稿与日志选择，无需发送测试反馈即可完成。 |

前三步可以显式跳过，跳过不会显示“已确认”或伪造网络结果。后五步以理解说明、查看入口为主，不要求为了学习额外调用模型、上传文件、启动诊断或提交反馈。

## 交互与恢复

- 教学卡放在当前页面内；新建会话和写反馈时放进表单的滚动区域，页面标题与表单原有按钮保持可用。
- 重新学习入口是普通设置行，使用名称、次级说明、小图标和箭头，不占用“更多”页标题上方。鱼皮肤在图标位使用小头像，不新增横幅或大立绘。
- 原有公告、更新提醒、审批弹窗、AI 排查面板和原生 dialog 优先，不叠加教学弹窗或抢焦点。
- 会话页限制教学卡高度，顶部可收起为一行；暂停后恢复普通页面。
- 本机保存的进度只有 schema、步骤和状态，不保存令牌、地址、会话 ID、消息、反馈草稿或日志。不增加统计上传。
- 第一条消息确认后，刷新恢复到“看懂回复”步骤，不要求用户重复发送练习消息。接受状态不跨连接或会话冒用。
- 示例只填空白输入框，不覆盖已有草稿、不代发；引导异常也不能把已确认发送变成发送失败。
- 反馈表单修复了未定义安全区变量导致 max-height 失效的问题；正文滚动，取消/提交按钮留在屏幕内。
- 完成只代表走过教学路径，不表示跳过的练习实际执行过，也不表示反馈已经发送。

## 代码落点

- `public/onboarding.js`、`public/onboarding.css`：任务说明、进度、就地教学与入口定位，零网络请求、零新增依赖。
- `public/app.js`：当前连接/会话状态适配、accepted 通知、现有页面操作、保护反馈草稿。
- `public/index.html`：加载组件资源；`public/workflow.js`：沿用原来的更新周期、清除本机数据时清理学习进度。
- `public/styles.css`：反馈弹窗安全区变量修正。
- `scripts/sync-plugin.mjs`：同步组件；`package.json`：语法检查；`tests/onboarding.test.js`：执行组件与真实发送控制器的行为测试。
- 根 `public/` 为源，同步生成插件内对应文件，不直接编辑副本。

## 验收边界

界面快速走查暂评 8/10：入口可发现性 2、状态反馈 2、控件与任务映射 2、不自动执行无关操作的约束 2；错误恢复暂不计分，仍需真正的新手在未配对、地址错误、权限拒绝与网络切换条件下独立完成任务。此评分是按 Design of Everyday Things 技能检查表进行的开发走查，不是用户研究结论。

自动化和隔离浏览器能验证状态、交互、布局和不代发边界；Android 相机配对、实际模型回复、真实主机网络切换和新手理解程度仍需要设备与用户验收。构建 APK 不等于已安装或发布。首次引导验证记录在 `dist/onboarding-validation-2026-10-22/`，rc.9 入口样式调整的记录在 `dist/rc9-guide-polish-2026-10-22/`；当前版本概览见 [rc.9 说明](rc-0.8.0-rc.9.md)。
