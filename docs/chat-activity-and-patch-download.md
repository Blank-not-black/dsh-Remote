# 对话活动精简与同版本安装包下载（2026-10-17）

## 对话界面

手机与桌面共用 `public/activity.js`。思考默认折叠，桌面可显示一行摘要，手机优先保留名称和状态，展开后读取正文。实时思考使用轻量状态点，遵循 reduced-motion。桌面助手回复去掉厚重气泡，正文与过程信息分出层次。

能通过 `callId` 和可用的 `turn` 信息匹配的 `tool/call`、`tool/result` 合并为一条活动记录；展开后分「参数」「结果」展示。只在显示层配对，原始历史、分页游标及缓存事件不删除、不修改。匹配不到的结果保留独立入口。助手消息内嵌的工具块也使用相同样式，不做没有身份依据的跨来源去重。

摘要使用「已调用」「已返回」「返回错误」，不会把“返回了结果”写成业务成功。工具名、摘要、参数、结果与思考均转义为文本，详情长度有界。工具故障保留文字与主题错误色。手机原有隐藏工具开关继续生效。

`HistoryView` 按稳定标识保留展开/收起状态，工具结果返回、思考分片替换或最终消息接管时不会无故折叠。只保存有限数量的界面状态，切换会话/连接时清理；原有上滑阅读锁定、锚点、回到最新和离开后恢复逻辑保留。

使用既有 `cognitive-psychology-ux` 与 `design-everyday-things` 的渐进披露、操作映射和状态反馈原则。启发式自查 **8/10**：过程入口、错误辨识、展开反馈和阅读位置有回归及隔离浏览器证据；真实任务中用户是否理解所有状态仍待实测，不视为用户研究评分。

## 重新下载安装包

入口：**手机端/App「更多 → 关于与维护 → 重新下载安装包」**。Web 手机布局也可使用该入口，校验后保存 APK；App 优先使用原生下载/安装桥。桌面本轮同步的是对话界面，未新增桌面网关二进制自更新入口。

即使「检查更新」显示已是最新版本、普通更新入口隐藏，仍可手动重新下载：

1. 锁定下载按钮，避免重复请求。
2. 使用 `cache: no-store` 与时间参数重新读取当前主机 `update.json`，跳过版本号大小比较。
3. 获取清单里的 APK 地址及 SHA-256，下载地址增加带时间与哈希片段的缓存参数；浏览器下载同样禁用缓存。
4. 沿用 SHA-256 校验、下载进度和原生安装流程。无哈希或校验不一致时拒绝保存/安装；清单读取后连接已切换时不启动旧主机安装包下载。失败后解锁，可显式重试。

这是重新获取主机提供的包，不会自动制造或发布同版本补丁。**主机上的新 APK 与对应 SHA-256 清单需要一起同步**；只替换 APK 而保留旧哈希会被拒绝。Android 最终仍由系统安装器处理签名、版本及安装授权，本功能不绕过这些检查。
