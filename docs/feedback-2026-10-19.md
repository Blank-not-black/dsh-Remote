## 对设计文档的处理意见

复用官方检索、明确空索引状态、按需读取 README、适配注册表保持单一来源的方向可落地。实施中固定四个边界：

1. 团队基线采用 `announcement-forms-and-teams.md` 已有真实快照验证的 `0.1.24-rc.1`；技能选择已实装核验的 `0.4.6`，费用选择 `1.8.17`，上下文保持文档基线 `0.64.0`。发现页的安装动作仍走既有预检/确认链路。
2. npm 根级 README 没有逐版本归档保证；返回的 latest 标签仅供参考，不能断言文档准确归属于某个指定版本。
3. 官方 compatibility 表示主机版本要求，不等于安全审查，也不替代现有 `dsh.bundle.patch` 安装门禁。索引含 Git 或其他 registry 的条目保持可浏览，Remote 不把它们偷偷改装成 npm 官方 registry 上的同名包。
4. 可选插件卡片只出现在“添加插件”，不会回到默认已安装页；不自动安装、不修改索引配置。
