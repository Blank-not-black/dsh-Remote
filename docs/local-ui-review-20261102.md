# 0.8.4 本地安装与 Android 模拟器 UI 验收

本轮将尚未合入 dev 的加密与审批摘要功能组合在独立本地验收分支，构建并安装 **0.8.4-rc.8 / Android 8024**。没有公开发布、部署云端、修改主机默认模型或替换其他插件。

## 实测发现与修正

1. 实际审批卡片没有预览夹具中的 `data-deck-kind="approval"`，新增高度规则未命中；摘要入口把允许/拒绝按钮推到 156px 卡片的滚动区域之外。改为匹配实际存在的 `data-session-approval`，完整显示常规摘要卡片，主操作触控高度从 36px 增至 44px。摘要按钮使用已有主题变量及次要操作字号，避免在浅色主题中边框和背景混在一起。
2. 长公告的整个卡片一起滚动，操作栏落在约 3000px 的正文后。改为头部、底部操作栏固定，正文与投票区域单独滚动；键盘可聚焦正文滚动区。
3. “稍后再看”没有延后状态，30 秒轮询重新弹出同批未读公告。增加按主机、按公告的页面内延后记录，保持未读与历史；新公告、强制公告继续提醒，新页面仍可提示旧未读公告。明确清理数据会清除延后记录。

改动源文件：`public/session-deck.css`、`public/styles.css`、`public/index.html`、`public/app.js`、`tests/announcement-poll-ui.test.js`；另同步相关插件副本和构建指纹。两个禁止提交的历史 app.js/index.html 副本仅在构建时同步，不纳入开发提交。

## 安装与检查

- 先识别真实 Desktop 主进程和 profile，确认无活动任务，备份控制文件、完整依赖树和 local-plugins；两轮备份均核对清单一致。模拟器升级前另备份原 App 私有数据。
- 本地 pnpm 安装后 206 份插件文件匹配归档，8 个无关依赖的内容及配置、访问凭证、中转绑定保持不变。Desktop 重启后健康检查、上游、mux/host collectors、两条已鉴权 WebSocket 和 21 份服务资源核验通过。
- RC.8 APK 签名、版本及 SHA-256 核验通过，167 份 APK 静态资源与构建副本一致，206 份插件归档文件逐字节匹配；安装后读回 versionCode 8024、versionName 0.8.4.rc.8。
- Windows WHPX 实际运行 Android 16 / API 36 模拟器，原始 ADB 截图为 1080×2400，WebView 为 412×839 CSS 像素。最终复查没有临时样式注入。
- 在最终 APK 里，带“UI 模拟请求/摘要”标记的内存夹具验证原生确认框取消零请求、确认一次请求、重绘和展开不重复生成、原文和命令完整、允许/拒绝完整可见且触控高度 44px、无横向溢出；退出时移除夹具及临时 fetch 包装。
- 真实历史长公告复查：正文可滚动，底部按钮在视口内；关闭后立即轮询不再弹出，已读数量不变。

## 默认模型与边界

用户授权后，只在新建的明确标记的本地 QA 会话测试默认模型，未改变全局默认模型或其他会话。模型查看了临时测试目录和虚构文本文件，没有删除文件；首轮等待较长，已停止，最终没有运行中任务。界面记录的该轮已知用量约 74.7K token，包含默认会话上下文与工具轮次，不能当作短摘要接口的额外用量或实际账单。

这轮未自然产生真实待人工审批请求，因此不声称真实付费模型已完成审批摘要端到端验收。上述审批界面数据明确为模拟夹具，未增加真实摘要模型调用。真实摘要质量、提供商计费及其他 Android 设备/鸿蒙、弱网、后台行为仍不在本轮验证范围。

本地候选和核验位于忽略目录 `dist/local-0.8.4-rc.8-ui-20261102/`；模拟器截图与只包含验收数据的报告位于主工作区忽略目录 `dist/local-ui-review-20261102/`；安装核验位于 `dist/local-install-0.8.4-rc.8-20261102/`。私有 profile 和 App 数据备份仅保存在用户私有备份目录，不纳入仓库。
