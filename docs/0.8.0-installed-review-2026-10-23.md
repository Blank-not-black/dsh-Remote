## 本次判断与改动

1. 插件状态接口确实应避免缓存。`packages/plugin/index.mjs` 在 `/remote/api/plugins/*` 分支设置 `cache-control: no-store`，成功及分支内错误响应均覆盖。隔离集成回归通过真实网关检查 200 和 404 的头部，以及未认证请求仍被拒绝。
2. 报告把“本地 0.8.0 显示更新至公网 rc.9”列为预期，但该按钮文案会误导用户。`public/plugin-center.js` 增加零依赖语义版本比较：正式版高于同号 RC，数字版本段按数值顺序比较，构建元数据不改变优先级。较旧版本显示“降级至”且默认禁用；只有明确指定版本并查看后才允许有意降级。无法比较的版本显示“切换至”，同样要求明确选版。
3. host WS 的握手、上游及事件轮询正常；当前重放集合按 session、queue、reasoning、jobs、approval、question 等事件构建，host 静默不产生这些基线。未添加虚假事件或改变双通道协议。
