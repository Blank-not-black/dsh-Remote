# 插件首次使用与 App 下载体验

2026-10-20，本地基线 `0.8.0-rc.6`。本记录描述源码改进与本地测试包，不代表已部署或公开发布。

## 用户流程

插件抽屉和管理页共用三步向导：准备电脑端、安装 Android App、在 App 中扫码连接。没有手机或 Web 客户端在线时，抽屉主按钮进入安装与连接引导；已有在线客户端时保留控制台入口。向导可以手动收起，轮询不会反复展开。

安装区域优先提供手机扫码下载。通过 HEAD 检查当前主机的 APK，显示更新元数据中的版本和实际文件大小；原生浏览器下载管理器负责下载进度和保存。插件增加精确的 `/remote/dsh-remote.apk` GET/HEAD 路由，因此网关关闭时也能在当前设备下载插件内的 APK。手机扫描的下载码指向选定网关地址，需要网关运行且手机能访问它。

下载码不包含访问凭据；连接码仅在主动点击后显示。独立设备密钥模式使用既有的添加设备流程，不生成共享令牌连接码。网关停止、状态读取失败或认证异常时清除新向导中的旧二维码。只有检测到 App/Web 客户端在线时才确认连接成功，管理页自身不计入。

包缺失或请求失败时提供重试与备用发行页；仅监听本机、无候选地址时显示修复指引。支持中文/英文，使用既有主题变量。完整使用步骤见[安装与首次连接](getting-started.md)。

## 本次文件清单

- `public/setup.js`、`public/setup.css`：共享引导、包可用性检查、地址选择与二维码。
- `public/plugin.html`、`public/plugin.js`：抽屉接入、首次使用主按钮、状态失效处理。
- `public/admin.html`、`public/admin.js`：管理页接入、共用地址偏好、设备密钥入口、原下载链接改为向导入口。
- `packages/plugin/index.mjs`：插件内 APK 的精确静态映射、下载响应头与流清理。
- `scripts/sync-plugin.mjs`：同步新增资源。
- `tests/setup-ui.test.js`、`tests/plugin-runtime.test.js`、`tests/token-recovery.test.js`：交互回归、真实 HTTP 下载、既有测试夹具兼容。
- `docs/getting-started.md`、本文件：使用说明与验收记录。

已执行 `npm run sync-plugin`，对应插件静态副本及构建诊断元数据随脚本生成。工作区原有其他未提交修改均保留；未提交、未推送、未部署。
