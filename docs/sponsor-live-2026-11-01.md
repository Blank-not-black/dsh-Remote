## 云端

- 申请端为 `https://relay-pilot.blankalwaysgoeson.site/sponsor/`，管理端为同域名 `/sponsor/admin`。两页及公开配置实际返回200，管理 API 未认证返回401，云端内部的正确审核凭据可读取管理 API。
- `enabled=true`、`accepting=true`，额度为服务月 5GB、单网关，不包含文件传输；名额上限79，包含原有有效资格。没有创建支付账户、代核付款或自动发送邮件。
- 为新资格配置专属 `*.relay-pilot.blankalwaysgoeson.site` DNS 和通配证书，避免随机租户域名签发后无法连接。新资格从该专属子域分配，原控制地址及已有租户域名不变。证书自动续期钩子复用服务器既有 DNS 工具，DNS 密钥没有下载到本机。
- 部署前停止专属中转进程并成组备份应用和状态；只变更该服务及其专属 Nginx 站点。上线检查先暂停申请，验证后开放。回环自检 Host 和回退复制属主曾出错，已修正；没有用旧备份覆盖其他 Nginx 业务。
- 真实 HTTPS 运营验证资格明确标记为“无付款的运营验证”，验证转发200、无令牌401、基础档文件接口403、服务月5GB和撤销后403；完成即撤销，没有伪造收款或审核记录。
- 管理密钥保存在云端私有运营目录。自动审批拒绝了将新建管理密钥下载并持久化到本机的操作，需要用户明确授权凭据转移；未用其他通道绕过。管理接口的云端内部鉴权已验证，密钥交付仍应单独如实报告。

## 客户端及冗余清理

主入口为手机/桌面的“更多 → 主机与连接 → 云服务器中转”。赞助申请链接固定可见，不依赖云端探测成功后才插入；暂停、满额及查询已有申请由申请页呈现。“关于与维护”的赞赏弹窗和网关管理页支持弹窗复用同一入口组件。

删除手机顶部赞赏/反馈按钮、旧反馈底部菜单、桌面隐藏反馈菜单及会话操作里的重复赞赏按钮，并移除其事件、关闭/切换函数、常量、失效焦点目标和专用样式。保留当前可见的反馈表单、AI 医生、管理页真实反馈菜单、普通赞赏二维码、首页医生入口、自定义选择抽屉及其共用样式。命令菜单和提示词预设原先借用旧反馈菜单的样式，已迁移到明确的 `ds-action-item`，未连带删除。

`sponsor-entry.js` 现在只提供一个共享入口组件，不再监听旧按钮 ID、探测后静默隐藏或创建重复链接；组件支持语言切换并保持 DOM 幂等。模块在中转设置前加载，管理页保留其 `/remote/admin/` 路由所需的相对资源路径。

验证覆盖实际插件挂载和资源、反馈、医生、命令/提示词样式引用、入口可见性、中转设置、会话与完整仓库门禁。历史同步副本 `packages/plugin/public/app.js` 和 `index.html` 不作为开发提交；构建安装包时仍由根 public 同步生成。

真实到账核验和人工邮件仍由运营者完成，不能用运营验证资格代替真实赞助流程。云端私有状态、审核凭据、截图及备份均不提交。
