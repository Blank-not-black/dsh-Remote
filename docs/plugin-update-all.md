# 一键更新主机插件（开发中，未发布）

手机与桌面共用“更多 → 主机插件 → 已安装 → 一键更新”。检查整个当前 profile，筛选只影响展示。先读取各插件 npm latest，再以精确版本统一预检并确认；不把 latest 直接交给安装命令，也不降级较新的 RC 或自定义版本。

主机维护的核心插件、非插件依赖、本地文件/目录链接/自定义来源不进入批量更新。读取失败、版本无法比较或 latest 不再声明 DSH bundle 的项目列出原因，其他项目仍可确认。Remote 本体放在最后，确认页明确说明是否包含它。旧主机能力接口未声明 updateAll 时按钮禁用。

请求沿用 `/remote/api/plugins/preflight`、`operations` 和 `state`，新增 `action: update-all`、固定逻辑名称 `all-plugins` 与最多 100 个 `{name, version}` 目标。服务端重新验证归属、来源、版本递增及目标 bundle；预检凭据绑定完整目标列表和配置。发布年龄检查包含整份旧锁文件及所有目标，任何豁免都需确认。客户端不能篡改目标、增加核心包或绕过预检。

单个独立 worker 持有整个 profile 的任务锁，先完整备份，然后逐个使用当前 DSH 自带 CLI 安装。每项固定精确版本、禁用脚本，保留原停用状态，核验 manifest/lockfile/node_modules 后记录结果。Remote 最后执行，worker 自带源码快照；页面关闭和 HTTP 断线不取消已受理任务。

任一项失败会停止后续项，保留已完成项和失败现场，不自动回滚；手动恢复使用整批开始前的备份。若失败后又修改插件或配置，恢复会拒绝覆盖。最终一致性核验失败时整批仍显示失败。更新后需重启 DSH，不自动重启。
