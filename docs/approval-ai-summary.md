# 人工审批的按需 AI 中文摘要

2026-11-03 实际提供商验证：按用户授权，在隔离的虚构待审批场景中，经实际网关、Remote摘要接口和DSH的真实LLM服务，调用本机配置的 `dsh-opencode-go / deepseek-v4.1-flash`。返回HTTP 200与中文摘要，耗时约10.7秒；重复请求复用结果，生成调用共1次，未确认时零调用，审批结束后409。没有发送完整工具参数或执行工具。此项验证真实模型链路，不等于自然审批事件或物理手机已经验收；512是输出上限，未保存实际token计数或账单金额。

自动审查转人工后，审批卡片继续显示原始理由、工具参数和允许一次/拒绝按钮。另提供“AI 中文总结（消耗 token）”，默认不调用模型。每次新生成前确认，只把工具名和审查理由交给当前会话配置的提供商/模型；不发送完整对话或工具参数。常见 Bearer、密钥字段、sk- 密钥和 URL 凭据/查询串会脱敏，但理由本身也应避免包含秘密。摘要是参考，不能作为授权或安全保证。

当前自动审查插件使用固定决策协议，没有可直接复用的中文摘要字段。本功能不修改该插件、风险策略或审批结果。未来若上游提供正式摘要字段，可再接入以减少额外调用。

## 消耗与失败行为

- 仅对自动审查未通过后仍待人工决定的请求提供入口；普通权限申请没有此按钮。
- 后端从仍在运行的会话日志确认待审批请求，使用主机确认的模型，不接受客户端提供理由、模型、提示词或任意正文，也不恢复/创建会话。
- 输入理由最多 2000 字符，输出请求上限 512 token，展示最多 240 字符；模型被要求一至两句、120 字以内。512 是请求上限，实际消耗按提供商计量，推理模型可能耗尽上限而无法给出摘要。
- 每个主机进程最多两个并发生成、每小时 20 次新生成；重复请求合并。服务端按会话、审批、理由、工具及模型缓存 20 分钟，包括失败或结果不确定的生成。缓存最多 64 条。超出上限直接提示不可用。
- 客户端保留至多 40 条内存结果，重绘不再调用。失败不自动重试。服务端重启/缓存到期或模型变更后再次主动生成可能再次产生费用。
- 15 秒服务端超时、18 秒客户端超时；错误仅显示固定提示，不暴露提供商内部错误。超时不能保证提供商未收费。
- 生成期间审批已完成、会话或模型变化，则不返回过期摘要；切换连接清理客户端缓存并取消请求。摘要没有独立本地持久化，完整原文仍使用既有审批流程。
- 摘要作为纯文本显示，不执行 Markdown、HTML、命令或工具。原始请求、允许/拒绝操作不会等待摘要。英文界面也可按需请求中文摘要。

## 接入与验收

`POST /remote/api/approval-summary` 必须通过网关控制权限及插件 Bearer 鉴权，JSON 仅接受 `sessionId`、`approvalId`、可选 `callId` 和明确的 `consent:true`。既有新旧 DSH 审批 wire ID 可能不同，后端使用同一会话的 callId 对照尚未结束的审计请求；缺少所需主机接口时返回不可用，不猜测。

现有单文件网关形态、零构建 JS 和零新增依赖保持。需要更新配套 Remote 插件才能提供此接口，单独升级网页不能绕过主机能力。此轮只覆盖 WebUI/Android 包内网页及桌面 WebUI，没有修改鸿蒙客户端。

测试使用临时用户目录、模拟模型和实际网关/插件转发，不调用真实收费模型，不读取真实会话内容或修改安装环境。覆盖取消、请求去重、失败缓存、权限、陈旧请求、模型变化、配额、脱敏和纯文本展示。模拟模型验证不能替代实际提供商的摘要质量、耗时和 token 账单验收。
