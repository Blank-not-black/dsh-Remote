# 0.8.2 发布准备与 0.8.1 全量差异

状态：本地发布准备，尚未公开发布。比较基线为正式标签 `v0.8.1`（`1f96d87`），候选范围包含当前工作区、任务分支及已更新的 `origin/dev`。正式执行发布仍需接受完整提交范围并按 dev → main 流程集成。

## 新增和修复

| 内容 | 0.8.1 → 0.8.2 的行为变化 | 适用范围 |
| --- | --- | --- |
| 局域网搜索电脑 | Android「更多 → 服务器 → 搜索电脑」发现同一 Wi-Fi 下开放配对的电脑；无需先手输 IP，首次连接仍需电脑显示的配对码 | Android；电脑使用插件或独立网关 |
| 限时设备配对 | 管理页启用独立设备密钥后，可开放 10 分钟窗口；20 位随机配对码、双向证明、临时 ECDH 与 AES-GCM 加密交接独立设备令牌；成功或过期关闭，不广播令牌 | 网关与 Android |
| 任务结果提醒 | 新增任务结束、目标完成、运行失败提醒；审批／提问和任务结果分别开关，独立系统通知通道，提供测试、权限及系统设置入口；点击通知跳转对应连接和会话 | Android |
| 通知去重与竞态修复 | host 状态确定运行周期，WS／轮询共用事件身份及有界持久回执；前后台补拉先处理 resolved 再决定是否提醒；审批测试返回实际投递结果 | Android 配套新网关 |
| 公告存储失败兜底 | 写入后读回验证，失败时使用 sessionStorage 和内存；覆盖公告历史、已读与填写标记，减少当前会话内反复弹出及静默丢状态 | 手机 Web／Android 的共享前端 |
| 诊断记录保留 | 记录公告、历史、RPC、连接与存储错误，附版本／构建指纹和脱敏占用统计；24 小时、160 条、约 48 KB 上限，保留关键错误，提供多存储备份 | 手机与桌面 Web 前端 |
| 诊断反馈附件 | 默认不勾选，用户自选后预览客户端与网关诊断；客户端、网关、收集器共享字段白名单；完整保存按报告编号确认，旧收集器无回执时明确提示 | 前端／网关；完整链路还需升级收集器 |
| 插件加载冲突修复 | Cordis bundle entry id 从通用 `dsh-remote` 改为包名 `dsh-remote-plugin`，避免与同名条目互相顶替，公开产品名称不变 | DSH 插件，来自 PR #25 |
| 问卷资料 | 随包公告新增重新开放的独立问卷 ID、季度总价和月均价说明；新旧轮次分别统计 | 随包公告内容，不代表新增收费或上线云中转 |

新增依赖数为零；网关仍为单文件，前端仍为零构建纯 JS。HarmonyOS 本轮没有实现 Android 的局域网发现或任务通知能力。

## 尚未实现与验收边界

1. **旧缓存自动迁移和总量回收尚未实现。** 只新增存储失败兜底及占用诊断，不能释放已经被旧缓存占用的容量。随包问卷历史内容曾承诺“下版”处理，发布前应明确接受这项范围缺口或另行实现；当前更新说明已明确不包含。详情见 [缓存计划](next-version-cache-cleanup.md)。
2. **完整诊断附件依赖收集器升级。** 本轮包含收集器代码和 schema，没有自动更新线上服务。旧收集器仍可保存受限摘要；没有匹配回执时不能宣称完整日志保存成功。隔离链路测试不等于线上部署。详情见 [诊断反馈](diagnostic-feedback.md)。
3. 局域网搜索依赖当前 Wi-Fi IPv4 广播可达，访客网络／AP 隔离或防火墙可能阻断；浏览器、HarmonyOS 继续原有连接方式。配对交接加密不代表后续普通 HTTP 全程加密。
4. 任务结果通知依赖 Android 系统通知权限和通道设置，后台仍受系统及厂商节电调度影响，不承诺常驻推送。峰谷提醒所有权保持在 dsh-cost-meter，本次没有改为手机自建规则。
5. 用户在本轮明确确认 RC2 的同一 Wi-Fi 搜索配对、息屏通知（声音／振动）、点击通知跳转及覆盖安装配置保留全部通过。此项是用户验收，区别于自动测试；正式版元数据和 PR #25 整合后的产物由本轮再做构建与一致性核验。
6. Windows 已有本地 RC2 运行证据；新正式版预备包不自动替换已安装 RC2。Linux／macOS 发布门禁需候选代码进入 CI 后验证；HAP 不在此发布流程内。

## 正式版产物准备

目标版本为 `0.8.2`，Android versionName `0.8.2`，versionCode 从 RC2 的 `8013` 递增到 `8014`。签名、applicationId、连接存储键保持不变。更新说明由根 `package.json.updateNotes` 维护，经构建和本地打包生成 update/history 与插件资源；不可把 RC2 APK 标成正式版。

本轮验证日志、APK／tgz、校验和、全量文件范围与准备状态均保存到 `dist/release-0.8.2-prep/`；构建结束后以其中的准备报告为准。
