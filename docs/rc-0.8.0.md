## 本轮变化

- 「更多 → 主机与连接 → 云服务器中转」及插件管理页可填写个人中转密钥，一次绑定主机并开启；展示公网地址、主机指纹、有效期、状态和每日剩余流量。客户端直接内置网关，保持单文件分发，无需额外工具或计划任务。使用设备访问密钥的用户需提供仅本次操作使用的主机管理令牌。
- 公网中转为限量邀请试测，个人密钥由运营者私下提供；每位测试者连接自己的 DSH。手机仍使用自己的 Remote 访问令牌。云端终止 TLS，运营者在技术上可接触经过的明文；本轮没有收费或自动购买功能。
- 云端按个人中转授权限制每日上传/下载合计 5GB（十进制 5,000,000,000 字节），北京时间零点重置。覆盖 HTTP 头/正文及 WS 帧，跨连接和服务重启持久化；超额关闭该租户传输，保留控制连接供零点恢复，不影响其他租户。写盘失败时暂停传输。崩溃可能保守多计不足 64KiB 预留及最后一个被拒传输块，不作为云厂商账单或收费计量。

rc.2 追加 Windows Remote 自更新修复：网关/监督进程工作目录改到用户运行数据目录，更新工作进程在 profile 内独立源码快照运行。Windows 测试重现旧 cwd 导致的目录锁，并验证真实网关运行中可以替换隔离插件目录。旧进程不会被此源码补丁改变，需要先退出旧 Desktop 与网关、重装目标版本再启动；实际反馈设备上其他锁或 ACL 尚未验证。详见[插件中心](plugin-center.md)。原 rc.1 本地产物保留用于比较。

- Android / 手机 Web / 桌面 Web 收敛为会话、文件、更多三个入口。待审批、待回答直接出现在会话首页；连接摘要可展开查看链路状态。
- 已选工作区时减少新会话步骤；已有目录可登记为工作区。原工作台的绑定、排序、批量发现保留在高级目录组织中，浏览和刷新不隐式登记目录。
- 普通发送固定排队，繁忙时显示插队按钮；模型与思考深度独立打开。导出、压缩、工作区文件可以直接从会话菜单执行。
- 设置分为主机连接、外观输入、模型提供方、通知后台、关于维护。主机插件和操作回执从更多页进入，空测试页入口移除，缓存/连接/全部配置分开清理。
- 常见聊天文本文件增加受限预览；Markdown 可切换源码。上传复用原有续传协议，增加超时、弱网小块和按耗时调整块大小。

## 弱网实现及边界

受支持的写入通过新网关持久化操作 ID，客户端只提交一次，响应丢失后只查结果。同一 ID 不同内容被拒绝。重启前未完成记账的操作标为结果未知，绝不自动重放；用户核对后可结束跟踪并自行决定是否提交新操作。回执默认保留 24 小时；不承诺旧 DSH 上跨进程崩溃的 exactly-once。

网关事件增加实例 epoch，处理重启后新序号已超过旧游标的情况，并提供当前待办重放基线。单个慢 WS 客户端积压有界，超限断开以进入既有恢复流程。工作区与目录组织读取并行、合并在途读取；读取失败保留已有列表。

插件导出使用异步受理/状态查询，旧同步路径放宽代理等待预算。导出任务状态仍是插件进程内状态，不承诺 DSH 重启后自动续接。

HTTP 局域网页面复用现有 SHA-256 兼容无 SubtleCrypto 场景；没有引入第三方依赖、前端构建器或数据库。主机别名不会自动合并，跨地址仍按连接身份隔离。

## 建议开发者先测

1. 从 0.7.x 升级，确认主机分组、令牌、主题和历史仍可用；常用功能在三个入口中能被找到。
2. 连续创建会话、发送消息、审批和回答，切到其他服务器再返回，确认没有错主机、错会话或重复执行。
3. 模型切换完成后发送；运行中分别使用排队和插队，核对队列与实际执行状态。
4. 提交瞬间断网 10～30 秒、恢复网络或刷新页面，先查操作回执，再核对主机日志；不要凭加载动画判断是否执行。
5. 审批待处理时重启网关，特别覆盖新进程序号超过旧游标；确认待办恢复，已处理请求不会重新变成待处理。
6. VPN/弱网下同时阅读长历史、接收流式回复和上传大文件；测试暂停、超时后继续、校验失败及同名文件冲突。
7. 测试异步导出、Markdown 预览、文件下载，以及后台通知、Doze、锁屏后恢复。
8. 分别测试清除缓存、移除单个连接、清除全部配置；核对其他连接与主机文件的保留范围。

反馈建议包含平台/屏幕尺寸、DSH/Remote 版本、连接方式、操作步骤、预期与实际结果、是否重复执行；仅在愿意提供时附已脱敏截图和操作编号，不提供令牌或私有会话正文。
